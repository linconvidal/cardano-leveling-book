Specifications for data representation, hash functions, signatures and secret protection.

  • Unicode Standard 17.0.0: characters, code points and encodings.
  • RFC 4648: Base16, Base32 and Base64.
  • NIST FIPS 180-4: secure hash functions, including SHA-256.
  • NIST FIPS 186-5: digital signature standards.
  • RFC 8032: EdDSA, Ed25519 and Ed448.
