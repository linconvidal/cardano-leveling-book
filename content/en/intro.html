About this guide

This guide accompanies the Cardano technical workshop and can be consulted before or after the sessions. The lessons combine explanations, runnable examples, and activities with explained answers.

The runnable examples use Pyodide to run Python in your browser. There is no need to install Python: the environment and libraries are loaded over the internet when you run the code. Execution requires JavaScript.

Code edits, answers, and results are saved locally in this browser when storage is available. They are not synchronized between devices; clearing site data may erase this work.

Without JavaScript, the text, code, and explained answers remain accessible, but execution and automatic checks are unavailable. To create a PDF, use your browser's print function.
