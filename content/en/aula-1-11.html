Objectives
  1. Find a transaction by its identifier.
  2. Locate the block, fee and size in an explorer.
  3. Check the same transaction on two sites.
Before you begin

An explorer is a website for looking up transactions, addresses and blocks. You do not need to connect a wallet to perform a lookup.

Guiding question

Where can I check a transaction and how much it paid in fees?

1. Explorers you can use

  • Cardanoscan
  • AdaStat
  • Cexplorer
  • explorer.cardano.org, which redirects to an explorer.

Networks have separate histories. A Preprod transaction must be looked up in the Preprod version of the explorer. The links in the example below already point to that network.

2. Open this Preprod transaction

This is the identifier of a real transaction:

d9b7a0b3c9bdb62e5a76d9ab675342be002c335a05e1be5d7bc04872bf99865f

Open the same transaction on Cardanoscan, on AdaStat or on Cexplorer.

The identifier may appear as Transaction ID, Transaction Hash or Tx Hash. Copy it to look up the transaction on another site.

3. Locate the fields

  • Block: indicates where the transaction was included. In this example, it is block 5114018.
  • Fee: the amount paid for processing the transaction. In this example, 600628 lovelace, equivalent to 0.600628 ADA. Do not confuse the fee with the amount sent.
  • Size: the serialized size of the transaction. In this example, 1473 bytes.

These values were queried through the Preprod Koios API on 17 September 2026. Explorers may use different names and formats to display the same data.

The inputs and outputs lists show the inputs consumed and the outputs created. Click an output address to open its page in the explorer and see other transactions associated with it.

4. Check another explorer

Activity: find the fee in two explorers

Open the Cardanoscan and AdaStat links above. Locate the identifier and fee on both sites. Confirm that you are looking at the same transaction.

If one site shows ADA and the other lovelace, use 1 ADA = 1000000 lovelace to compare them.

Check answer

The fee is 600628 lovelace, or 0.600628 ADA. The identifier should be the same on both pages. Compare the transaction data, not the appearance of the screens.

What we learned

  • Cardanoscan, AdaStat and Cexplorer let you look up transactions; explorer.cardano.org provides a redirect.
  • The identifier lets you find the same transaction in another explorer on the same network.
  • Block, fee and size are distinct fields. ADA and lovelace express the same value in different units.
