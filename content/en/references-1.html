Module 1 references

Consult the specifications and operational documentation when you need the network's exact rules.

  • Cardano architecture: overview of the components.
  • Ouroboros consensus documentation: consensus and chain selection.
  • CIP-1: the process for drafting and reviewing Cardano Improvement Proposals.
  • CIP-1694: governance participants, actions, ratification and enactment.
  • CIP-5: Bech32 prefixes for addresses and other Cardano objects.
  • CIP-19: the structure and encoding of Cardano addresses.
  • RFC 8949: the CBOR format.
  • Cardano Ledger: implementation, specifications and rules by era.
  • Cardano Docs: EUTxO: the model of consumed and created outputs.
  • Cardano Developer Portal: fees: size, parameters and execution costs.
  • Cardano Developer Portal: transactions: anatomy, auxiliary data and visibility to scripts.
  • Cardano Developer Portal: native tokens: policies, minting, burning and asset identification.
  • CIP-25: media-token metadata under label 721, including publication and update conditions.
  • RFC 8032: Ed25519, formats and test vectors. Ed25519ctx and Ed25519ph are distinct variants, not interchangeable API names.
  • CIP-1852: hierarchical derivation paths for Cardano wallets.
  • CIP-30: the interface for access, partial signing, witness sets and submission between dApps and wallets.
  • CIP-10: the registry of transaction metadata labels.
  • RFC 8785: JSON Canonicalization Scheme, for profiles that commit to canonical JSON rather than a file's complete bytes.
  • Cardano Developer Portal: smart contracts: validators, datum, redeemer and eUTxO transitions.
  • CIP-31 and CIP-32: reference inputs and inline datums.
  • CIP-40: collateral outputs; also check the ledger rules and parameters for the era.
  • CIP-67 and CIP-68: labeled asset-name prefixes, User Token classes and the datum metadata wrapper.
